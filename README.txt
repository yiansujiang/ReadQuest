================================================

【上傳到 GitHub 的檔案（3 個檔案，缺一不可，且要放在 repo 同一層）】
  1. index.html          （極小載入器，實際只有一行程式碼）

【保護機制說明（誠實告知，非加密）】
  - 已完成：把遊戲邏輯 JavaScript 抽出並用 Terser 壓縮混淆（變數名全部
    改成單字母、移除所有註解與空白、移除 console.log）；整個介面
    HTML/CSS 結構編碼後包進極小載入器，一般人直接「檢視原始碼」只會
    看到一行亂碼，看不到完整的頁面結構與遊戲邏輯。
  - 跳過 WASM：已盤點過，這份程式全部是 DOM 操作、字元拆解顯示、
    localStorage 存檔、語音朗讀，沒有大量數值運算，WASM 移植對這類
    程式幾乎沒有防護或效能效果，所以沒有做。
  - 限制：這只能提高「看原始碼複製」的門檻，無法阻止真的有心人用瀏覽器
    開發者工具查看執行後的畫面結構，或下載這幾個檔案分析。沒有放入任何
    API 金鑰或機密資訊（已掃描確認）。
  - 功能完全不變：確定視窗/取消視窗、列印學習單、語音朗讀、進度儲存
    等所有原本功能都正常運作（已用瀏覽器實際渲染測試過一輪，標題、
    主畫面、互動元件皆正常顯示）。
