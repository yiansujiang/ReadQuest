《文意偵探》課文預習策略學習系統 v6.7 
================================================
讓「不知道怎麼預習」的孩子，也能找到自己的閱讀方法
在資源班的教學現場，我常看到一個問題：
當孩子拿到一本新的國語課本，他知道老師說「回家先預習」，卻不知道到底要預習什麼。
是把課文讀幾遍？
還是查生字？
哪些詞語需要注意？
一句話應該怎麼讀？
一個段落又要看懂什麼？
對閱讀能力較弱的孩子而言，「預習」不是一句「回去自己看」就能完成的任務。
所以，我設計了《文意偵探》。
我希望把原本抽象的「預習」，轉化成一條看得見、做得到、有步驟的閱讀路徑。
🕵️ 四階段偵探任務
🔸 第一關｜生字掃描
圈出生字，找出自己閱讀時真正卡住的地方。
🔸 第二關｜情報照相機
框選關鍵語詞，學習從課文中抓出重要訊息。
🔸 第三關｜斷點分析儀
尋找適當斷點，練習掌握句子的閱讀節奏。
🔸 第四關｜檔案歸類
切分段落、貼上結構標籤，逐漸看見文章的組織與脈絡。
而我特別希望孩子能學會一件事：
「知道自己哪裡不會。」
完成閱讀任務後，學生可以自己選取需要加強的困難生字與語詞，系統再針對這些內容設計「精熟練習」關卡，提供🃏閃卡翻牌、🔗配對連線、👂聽音辨字、✏️造詞填空等不同練習方式。
